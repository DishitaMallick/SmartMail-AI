# SmartMail AI

SmartMail AI is an AI-powered email organizer that simplifies inbox management by categorizing emails, assigning priorities, generating short summaries and identifying important tasks and deadlines.

## Features

- AI-powered email summaries and prioritization
- Smart email categorization
- Action and deadline detection
- Search and filtering
- AI-assisted reply drafting
- Gmail integration with secure Google OAuth
- UX research and UI design using Figma

## Tech Stack

React, Python, FastAPI, SQLite, Gmail API, Google OAuth, NLP, Figma.

## UX Design

Designed user personas, journey maps, user flows, wireframes and high-fidelity interfaces to create a clear, action-focused email experience.

*Less inbox chaos. More clarity.*
